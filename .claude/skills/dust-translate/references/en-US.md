# en-US style guide

`en-US` is the source locale: these rules apply to the English text written in the code (the
Lingui messages), not to a translation. Voice and wording follow the `dust-ux-writing` skill.

## Spelling

American spelling, as listed first in Merriam-Webster.

| Rule | Write | Never |
|---|---|---|
| `-ize`, `-ization` | organize, customize, summarize, authorization, synchronization | organise, customise, authorisation |
| `-yze` | analyze, analyzing | analyse |
| `-or` | color, favorite, behavior | colour, favourite, behaviour |
| `-er` | center, meter | centre, metre |
| Single `l` before a suffix | canceled, canceling, labeled, unlabeled, totaling, modeling, traveled | cancelled, labelled, totalling, modelling |
| `-og` | catalog, analog | catalogue, analogue |
| Others | enrollment, fulfill, license (noun and verb), gray, toward, inquiry | enrolment, fulfil, licence, grey, towards, enquiry |

`cancellation` keeps both `l`s. `dialog` is the UI element; `dialogue` is a conversation between
people.

## Typography

- Apostrophe: typographic `’` (U+2019), not `'`: "Don’t", "agent’s".

## Exceptions

Keep the original spelling of:

- Product, brand and plan names, and code-defined names (skill names, space names).
- Labels quoted from a third-party UI, such as a menu path to follow in a provider's console.
- Protocol and API terms shown as field names, such as an OAuth "Authorization URL".
