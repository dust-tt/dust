# Benchmark method

The clean comparison has three independent systems running in parallel: one RocksDB/Tantivy server and client; three FDB plus three ES servers and a client; three TiKV plus three ES servers and a client. All hosts use Titanium NVMe Local SSD.

[Method](../../dfs-bench/docs/METHOD.md), [topology diagram](../../dfs-bench/docs/TOPOLOGY.md), [full results](../../dfs-bench/docs/RESULTS.md). Previous benchmark artifacts and fleets were removed.
