- **Memory primitives:** [memory.rs](../src/memory.rs), [ingest.rs](../src/lexical/ingest.rs), [store.rs](../src/store.rs). Native memtable/arena sizing follows the shared write-buffer budget. Defaults: 128 MiB cache, 64 MiB write buffers charged inside it; write buffers require at least 1 MiB and cannot exceed cache capacity. Native pins can overshoot the non-strict cache; these settings do not bound RSS.
- **Projection foundation:** [projection.rs](../src/lexical/projection.rs) uses owned RocksDB snapshots through `self_cell`; [membership.rs](../src/lexical/membership.rs) encodes empty chunks as absent keys, singletons directly, and larger sets as one bounded Roaring array container. Batches bind their originating database/generation; edits coalesce touched chunks. These primitives are tested but are not connected to serving search or cross-engine commit/recovery. Benchmark chunk size/encoding before freezing the format.
- **Concurrency:** [matrix](CONCURRENT_OPERATIONS.md), [shared RPC oracle](../tests/support/namespace_races.rs), [RPC benchmark](../src/bin/dfs-race-bench.rs), and [two-mount benchmark](../scripts/namespace-mount-races.py). Define expected errors and final identities/content for both serial orders; test simultaneous execution, path reuse, permissions, retained handles, retries, and persisted reopen.
- **Failure correction:** an uncertain disconnected write can block reopen on the same mount. The failure harness now verifies that error and successful reconciliation through a fresh mount. The legacy mount supports publication-only synchronization; the default one-second mount retains its explicit persistence path.
- **Compatibility:** the tested increment preserves wire formats and publication/persistence semantics. The RPC admission helper changes only its internal error representation. The rename benchmark now lives inside this crate. Newer backend integrations need separate validation.
- **Reproduction:** [cloud check runner](../scripts/server-implementation-check.py), [campaign runner](../scripts/server-implementation-campaign.py), and [Clean benchmark](../../dfs-bench/docs/RESULTS.md). All execution remains cloud-only under [DEPLOYMENT.md](../DEPLOYMENT.md).

Measure namespace/body visibility separately, plus fitting hot sets and random access over datasets several times larger than the pod limit. Million-file visibility and bounded recovery remain validation work.
